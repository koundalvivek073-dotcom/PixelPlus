# PixelPlus

PixelPlus is a responsive image-discovery web application built with HTML, CSS, and JavaScript that allows users to search and explore high-quality visuals. The app features a clean header, interactive search controls, quick-pick topic suggestion chips, and an empty-state guide message to direct first-time visitors.

For the design, I implemented a sticky top navigation bar so the search controls remain accessible as users scroll through image results. Additionally, I added a row of clickable category suggestion chips (like Nature, Architecture, and Tech) to let users trigger popular search queries with a single click.
